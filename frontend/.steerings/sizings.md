# Sizing Preferences

## Main Element Padding

- **Vertical padding**: 32px
- **Horizontal padding**: 48px

## Typography

- **Header size**: `text-[32px]` (32px / 2rem)
- **Status/Labels**: `text-[8px]` (8px / 0.5rem)
- **Tabs/Navigation Labels**: `text-[11px]` (11px / 0.6875rem)

## Screen/Feature Description

- **Font size**: `text-sm` (14px / 0.875rem)
- **Font weight**: `font-light` (300)
- **Line height**: `leading-relaxed` (1.625)
- **Text color**:
  - Light mode: `text-slate-500` (#64748b)
  - Dark mode: `text-slate-400` (#94a3b8)
- **Max width**: `max-w-xl` (576px / 36rem)
- **Usage**: Descriptive text below headers explaining screen/feature purpose

## Cards

### Card Padding

- **Horizontal padding**: `px-4` (16px)
- **Top padding**: `pt-4` (16px)
- **Bottom padding**: `pb-3` (12px)
- **Gap between card elements**: `gap-4` (16px)

### Card Header

- **Font size**: `text-sm` (14px / 0.875rem)
- **Font weight**: `font-bold` (700)
- **Line height**: `leading-[1.2]` (1.2)
- **Letter spacing**: `tracking-tight` (-0.025em)

## Main Content

- **Font size**: `text-xs` (12px / 0.75rem)
- **Font weight**: `font-medium` (500)
- **Line height**: `leading-relaxed` (1.625)
- **Max width**: `max-w-2xl` (672px / 42rem)

## Actionable Buttons

- **Height**:
  - **Actions**: `h-8` (32px / 2rem)
  - **Navigation**: `h-9` (36px / 2.25rem)
- **Horizontal padding**: `px-3` (Actions) or `px-4` (Navigation)
- **Font size**: `text-[11px]` (11px / 0.6875rem)
- **Font weight**: `font-medium` (500)
- **Gap between icon and text**: `gap-2` (8px / 0.5rem)
- **Icon Size**: `text-[14px]` or `text-[12px]` (Reduced from 16px/18px)
- **Border radius**:
  - **Actions**: `rounded-full` (9999px)
  - **Navigation**: `rounded-md` (6px / 0.375rem)
- **Border width**: `border` (1px)

## Tables

### Table Headers (`th`)

- **Font size**: `text-[10px]` (10px / 0.625rem)
- **Font weight**: `font-bold` (700)
- **Text transform**: `uppercase`
- **Letter spacing**: `tracking-widest` (0.1em)
- **Vertical padding**: `py-2.5` (10px)
- **Horizontal padding**: `px-3` (12px)
- **Text color**:
  - Light mode: `text-slate-400` (#94a3b8)
  - Dark mode: `text-slate-500` (#64748b)

### Table Rows

#### Paper Title (`h4`)

- **Font size**: `text-[13px]` (13px / 0.8125rem)
- **Font weight**: `font-bold` (700)
- **Line height**: `leading-[1.3]` (1.3)
- **Letter spacing**: `tracking-tight` (-0.025em)
- **Text truncation**: `line-clamp-2` (2 lines max)

#### Keywords (`span`)

- **Font size**: `text-[10px]` (10px / 0.625rem)
- **Font weight**: `font-medium` (500)
- **Text color**:
  - Light mode: `text-slate-400` (#94a3b8)
  - Dark mode: `text-slate-500` (#64748b)

#### Track (`span`)

- **Font size**: `text-[11px]` (11px / 0.6875rem)
- **Font weight**: `font-medium` (500)
- **Text color**:
  - Light mode: `text-slate-500` (#64748b)
  - Dark mode: `text-slate-400` (#94a3b8)

#### Index Number (`span.font-mono`)

- **Font size**: `text-[11px]` (11px / 0.6875rem)
- **Font family**: `font-mono` (monospace)
- **Font weight**: `font-medium` (500)
- **Text color**:
  - Light mode: `text-slate-400` (#94a3b8)
  - Dark mode: `text-slate-500` (#64748b)

#### Status Badge (`span`)

- **Font size**: `text-[9px]` (9px / 0.5625rem)
- **Font weight**: `font-bold` (700)
- **Text transform**: `uppercase`
- **Letter spacing**: `tracking-wider` (0.05em)
- **Padding**: `px-2 py-0.5` (8px horizontal, 2px vertical)
- **Border radius**: `rounded` (4px)
- **Display**: `inline-flex items-center`
- **Gap**: `gap-1.5` (6px)
- **Note**: Status badges do NOT include dot indicators - only text labels are displayed

#### Action Button (`button`)

- **Height**: `h-7` (28px / 1.75rem)
- **Horizontal padding**: `px-2.5` (10px)
- **Font size**: `text-[9px]` (9px / 0.5625rem)
- **Font weight**: `font-bold` (700)
- **Text transform**: `uppercase`
- **Letter spacing**: `tracking-wider` (0.05em)
- **Icon size**: `text-[16px]` (16px / 1rem) for material-symbols-outlined
- **Gap between text and icon**: `gap-1.5` (6px / 0.375rem)
