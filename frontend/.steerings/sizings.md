# Sizing Preferences

## Main Element Padding

- **Vertical padding**: 32px
- **Horizontal padding**: 48px

## Typography

- **Header size**: `text-[32px]` (32px / 2rem)
- **Status/Labels**: `text-[8px]` (8px / 0.5rem)
- **Tabs/Navigation Labels**: `text-[11px]` (11px / 0.6875rem)

## Screen/Feature Description

- **Font size**: `text-sm` (14px / 0.875rem)
- **Font weight**: `font-light` (300)
- **Line height**: `leading-relaxed` (1.625)
- **Text color**:
  - Light mode: `text-slate-500` (#64748b)
  - Dark mode: `text-slate-400` (#94a3b8)
- **Max width**: `max-w-xl` (576px / 36rem)
- **Usage**: Descriptive text below headers explaining screen/feature purpose

## Cards

### Card Padding

- **Horizontal padding**: `px-4` (16px)
- **Top padding**: `pt-4` (16px)
- **Bottom padding**: `pb-3` (12px)
- **Gap between card elements**: `gap-4` (16px)

### Card Header

- **Font size**: `text-sm` (14px / 0.875rem)
- **Font weight**: `font-bold` (700)
- **Line height**: `leading-[1.2]` (1.2)
- **Letter spacing**: `tracking-tight` (-0.025em)

## Main Content

- **Font size**: `text-xs` (12px / 0.75rem)
- **Font weight**: `font-medium` (500)
- **Line height**: `leading-relaxed` (1.625)
- **Max width**: `max-w-2xl` (672px / 42rem)

## Actionable Buttons

- **Height**:
  - **Actions**: `h-8` (32px / 2rem)
  - **Navigation**: `h-9` (36px / 2.25rem)
- **Horizontal padding**: `px-3` (Actions) or `px-4` (Navigation)
- **Font size**: `text-[11px]` (11px / 0.6875rem)
- **Font weight**: `font-medium` (500)
- **Gap between icon and text**: `gap-2` (8px / 0.5rem)
- **Icon Size**: `text-[14px]` or `text-[12px]` (Reduced from 16px/18px)
- **Border radius**:
  - **Actions**: `rounded-full` (9999px)
  - **Navigation**: `rounded-md` (6px / 0.375rem)
- **Border width**: `border` (1px)
